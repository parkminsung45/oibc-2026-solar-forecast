# 제출 파이프라인 (solution/)

## 재현
```bash
cd solution && source ../.venv/bin/activate
python features.py                                   # 특징 캐시 → ../cache/feat_{train,test}.parquet
python oof2.py lgb xgb nn_e4_bs16k nn_e4_bs16k_p3    # 구성용 2년치 OOF (~1시간)
python final2.py                                     # 구성 최적화 + 13개 모델 전 기간 학습 + 제출 파일 (~30분)
# → submission/composition.csv, submission/forecast.csv   (이전 버전: submission_v1/)
```
xgboost·lightgbm은 sklearn 번들 libomp를 패키지 lib/에 복사해 쓴다 (Homebrew 없음).
NN은 PyTorch(MPS) 필요.

## 방법
- 점수의 수익항은 구성과 무관한 상수 → **집합별 SMP·k 가중 절대오차 합 최소화**가 목표
- 예측: 발전소별 모델 → 집합 합산. 특징 = 예보 A·B의 라운드 10·17 동시 사용, t±1·일평균·지역평균 맥락,
  라운드 간 변화량, 구간적분 청천일사(csky)와 csky×(1−운량), 태양 기하, 계절
- 타깃 = 설비이용률 / 청천일사 (가중치 csky²), 최근성 가중 exp(−경과일/730)
- **`wa_ground_press` 제외**: 평가 구간 2026-01 중순부터 일부 지점이 지면기압(최저 924 hPa)으로 바뀌어
  학습 분포와 어긋남. 포함 시 NN 예측이 2026-01~05에 3~7% 낮아졌다
- 앙상블: GBDT 5개(LightGBM 3 + XGBoost 2) 평균 40% + MLP 8개 평균 60% (`tune.py` CONFIGS, `nn.py`)
  - MLP는 4에폭·배치 16k로 짧게 학습할 때 가장 좋음 (12에폭은 과적합)
- 구성: 2023-06~2025-05 주 단위 4-fold OOF 앙상블 잔차로 Σ w(|E_G1|+|E_G2|) 국소탐색 (각 집합 ≥ 20,001 kW)

동일 설정의 시드만 바꿔도 합이 ±2M 흔들리므로 단일 설정 간 작은 차이는 채택 근거로 쓰지 않았다.
